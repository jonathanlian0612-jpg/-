# 象日 SYMBOL ART 官方網站

使用 Vite 的繁體中文響應式單頁網站。

## 本機開發

```sh
npm ci
npm run dev
```

## 正式建置

```sh
npm run build
npm run preview
```

將 `dist/` 部署至靜態網站託管服務即可。

## 內容確認
